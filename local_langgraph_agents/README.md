# Local LangGraph Agents with Ollama

## Setup

1. Install Ollama
2. Pull the model:

```bash
ollama pull gemma2:2b
```

3. Install Python dependencies:

```bash
pip install -r requirements.txt
```

4. Run the app:

```bash
python app.py
```

## Example input

Create a Python script that reads a CSV file and prints total sales by region.
